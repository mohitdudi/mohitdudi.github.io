Introduction#

  • R can be regarded as an implementation of the S language which was developed at Bell Laboratories

  • Expression-language, case sensitive

  • Special symbols allowed are . (dot) and _ (underscore)

  • If name must start with ‘.’ or a letter, and if it starts with ‘.’ the second character must not be a digit. Names are effectively unlimited in length.

  • Semicolon or newline separate commands

  • Execute commands stored in a R file

    source("commands.R")

  • Output data to an external file

    sink("record.lis") # writes the output to record.lis instead of printing it to stdout

  • objects() or ls() returns the object currently stored in the session

  • rm() can be used to remove an object

    rm(list = ls()) # remove every object present in memory

Packages#

  • library() function (with no args) returns list of installed packages
  • getOption("defaultPackages") returns the list of packages automatically loaded during startup
  • chooseCRANmirror() function provides a menu to choose a mirror
  • setRepositories() function provides a menu to select the repos you want to use
  • update.packages() simply updates all existing packages
  • search() returns list of loaded packages

Tables (Frames)#

  • tbName[row, column] gives a element stored at particular row and column of a table

  • tbName[, 1] gives the first column of table

  • tbName$columnName gives you list of elements in the given column

  • rowNames(votes) gives you the list of row names, and colNames(votes) gives the list of column names

  • ncol(votes) returns number of columns and nrow(votes) returns number of columns

  • unique(votes$voter_category) returns a vector of unique values present inside voter_category column

votes <- read.csv("election.csv")
                                        # votes$poll # returns vector of values in poll column
                                        # votes$poll + votes $mail # this adds up the values of the given two columns for each row
votes$total <- votes$poll + votes$mail # create a new column that contains sum of poll and mail value for each row

                                        # write data back to a csv file, row.names prints the row indexes
write.csv(votes, "election.csv", row.names = FALSE)

# replaces the values with labels, and excludes -1
factor(votes$Q21,

Vectors#

  • Create a vector from existing vector

    marks <- c(15, 19, 10, 9, 20, 5)
marksFailed <- marks[c(4, 6)] # 9, 5
marksPassed <- marks[-c(4, 6)] # 15, 19, 10, 20

  • Relational operations on vectors

    marks <- c(15, 19, 10, 9, 20, 5)
marks > 10 # TRUE TRUE FALSE FALSE TRUE FALSE

  • which() function can be used, it returns the indices of elements that are true

    marks <- c(15, 19, 10, 9, 20, 5)
which(marks > 10) # 1 2 5
marks[(which(marks > 10))] # 15, 19, 20

  • vectors use & and | for logical operations, while && and || are used for single values

  • any() function tells if there is any value that satisfies the condition or not

    marks <- c(15, 19, 10, 9, 20, 5)
any(marks > 10)

  • all() is the opposite of any() and tells if all of the elements of vector satisfy the condition or not

Help#

  • help.start() loads the R documentation in html
  • If you use help() it will look for the item’s help page. If it doesn’t encounter any conflicts, then it will just present the man page otherwise it will show the search results
  • Alternatively you can use help.search("crayon") or ??crayon 1 to search for man pages, instead of directly loading the relevant one
  • example("crayon") 1 will return an example usage of the topic
?mpg # returns info about mpg dataset
help(mpg) # alternative way

?View() # returns info about View() function
